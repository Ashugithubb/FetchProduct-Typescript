# 🛍️ Simple E-Commerce Web App

A **React + TypeScript** based simple e-commerce web application that fetches product data from an external API and displays it on the page. The app includes **user authentication (Sign Up & Login)** and **pagination** for smooth product browsing.

---

## 🚀 Features

* 🧾 **Product Listing:** Fetches and displays product data from a public API
* 🔐 **Authentication:** User Sign Up and Login functionality
* 📄 **Pagination:** Easy navigation through multiple pages of products
* 💻 **Responsive UI:** Works seamlessly across desktop and mobile devices
* ⚡ **TypeScript Support:** Strongly typed for better scalability and maintainability

## 📦 Installation & Setup

1. **Clone the repository**

   ```bash
   git clone [https://github.com/your-username/simple-ecommerce-app.git](https://github.com/Ashugithubb/FetchProduct-Typescript.git)
   cd simple-ecommerce-app
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the development server**

   ```bash
   npm run dev
   ```

4. **Open the app**

   ```
   http://localhost:5173/
   ```
